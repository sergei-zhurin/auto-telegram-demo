# Автоматизация публикации музыкальных новостей

Демо-проект на Python для полного цикла работы с новостями: от сбора материалов с музыкальных сайтов до их отбора и публикации в Telegram и X. Конвейер объединяет веб-парсинг, фильтрацию и дедупликацию, редакторский отбор с помощью OpenAI, локальную модель для поиска срочных новостей и хранение истории публикаций.

## Пайплайн публикации

Каждый запуск выполняет один проход обработки. Режим публикации определяется текущим временем и расписанием в `main.py`.

1. **Сбор материалов.** `config.py` задаёт список новостных сайтов, а `parsers.py` содержит отдельные правила извлечения данных для каждого источника. `requests` загружает страницы, `Beautiful Soup` и `lxml` разбирают HTML. Результат приводится к общему формату: заголовок, описание, дата, ссылка и данные об изображении.
2. **Проверка истории и фильтрация.** `core.py` загружает локальные JSON-хранилища из `data/`, исключает уже опубликованные ссылки и отбирает новости по дате. Для поиска похожих материалов используются TF-IDF-векторы и косинусное сходство из `scikit-learn`.
3. **Выбор новости.** В обычном режиме OpenAI выбирает материал по редакторскому промпту и контексту предыдущих публикаций. В режиме срочных новостей локальная модель `all-MiniLM-L6-v2` и центроиды тематических категорий предварительно фильтруют кандидатов; затем OpenAI проверяет их по более строгим критериям breaking news. Модель работает локально на CPU.
4. **Публикация в Telegram.** `pyTelegramBotAPI` отправляет выбранную новость в заданный чат или канал. `Pillow` используется для подготовки изображения и добавления фотокредита; если изображение не удалось обработать, отправляется текстовый пост.
5. **Публикация в X.** `Tweepy` публикует последнюю новость из Telegram-хранилища и проверяет отдельную историю X, чтобы не отправлять ту же ссылку повторно. Публикация выполняется, когда совпадают условия расписания.
6. **Сохранение результата и ошибки.** После успешной отправки ссылка добавляется в JSON-историю. Модуль `logging` собирает сообщения о ходе выполнения; при ошибках бот отправляет лог в настроенный чат оповещений.

## Структура проекта

```text
.
├── main.py                     # точка входа, расписание и сценарии публикации
├── config.py                   # источники новостей, интеграции, пути и промпты
├── parsers.py                  # парсеры страниц новостных сайтов
├── core.py                     # фильтрация, отбор, форматирование и публикация
├── legacy.py                   # прежний фильтр срочных новостей по ключевым словам
├── utils.py                    # расчёт центроидов категорий для фильтрации новостей
├── requirements.txt            # зависимости Python-проекта
├── .env.example                # шаблон локальных переменных окружения
├── data/
│   └── centroids_bn.json       # центроиды тематических категорий breaking news
├── models/all-MiniLM-L6-v2/    # локальная модель Sentence Transformers
├── visualization/              # шрифт для оформления изображений
└── notebooks/
    └── parsing_ny_times.ipynb  # пример исследования парсинга в Jupyter Notebook
```

Рабочие истории публикаций также хранятся в `data/`, но создаются локально и не включаются в репозиторий.

## Запуск

Запускать из корня проекта. Потребуются Python 3.10–3.12, доступ в интернет, Telegram-боты с правом публикации, учётные данные X API и ключ OpenAI.

1. **Создать виртуальное окружение:**

   ```bash
   python -m venv .venv
   ```

2. **Активировать окружение и установить зависимости:**

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

   macOS/Linux:

   ```bash
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

3. **Создать файл настроек:** скопировать `.env.example` в `.env`.

   ```powershell
   Copy-Item .env.example .env
   ```

   ```bash
   cp .env.example .env
   ```

4. **Настроить `.env`:** указать токены Telegram-ботов, ID промежуточного, основного и чата оповещений, ссылку `TELEGRAM_CHANNEL_LINK`, ключ OpenAI и учётные данные X API. Для теста использовать собственные тестовые чаты и аккаунты. `.env` уже исключён из Git.

5. **Запустить один проход публикации:**

   ```bash
   python main.py
   ```

`main.py` завершается после одного прохода. Для регулярной работы добавить команду в планировщик операционной системы (например, Task Scheduler или cron), указав каталог проекта и Python из `.venv`. Не запускать параллельные экземпляры: они используют общие файлы истории.

## Данные и настройки

История публикаций создаётся в `data/` и нужна для дедупликации между запусками. Эти локальные JSON-файлы исключены из Git; при переносе проекта сохранить их резервную копию. Список интеграций, переменных окружения и примеры значений находятся в `config.py` и `.env.example`.

Версии библиотек закреплены в `requirements.txt`. Для выбора новостей и обработки текста используются модели OpenAI, указанные в `core.py`; доступность этих моделей зависит от настроек API-аккаунта. Разметка сайтов-источников со временем меняется, поэтому отдельные парсеры могут потребовать обновления.
